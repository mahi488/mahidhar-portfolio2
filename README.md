# Mahidhar Reddy — Portfolio

A responsive, Netflix-inspired personal portfolio starter for software development and cybersecurity opportunities.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. For editing, open the folder in Visual Studio Code.

## Before publishing — personalisation checklist
- [ ] Replace `assets/images/profile-placeholder.svg` with your own photo. Save it as `profile.jpg` and update the image path in `index.html`, or keep the placeholder until ready.
- [ ] Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
- [ ] Verify your LinkedIn and GitHub profile links.
- [ ] Add your exact college name, degree dates and graduation year.
- [ ] Add accurate descriptions, technology stacks, screenshots and individual repository/demo links for each project.
- [ ] Add your latest resume as `assets/resume/Mahidhar-Reddy-Resume.pdf` and add a download link when ready.
- [ ] Verify every skill listed reflects your actual experience.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — profile selection, mobile navigation and interactions
- `assets/images/` — profile photo and visual assets
- `assets/resume/` — resume PDF

## Notes
This is the Phase 1 foundation. Content marked for replacement is intentionally not presented as verified experience. Update it before sharing the live site with recruiters.
